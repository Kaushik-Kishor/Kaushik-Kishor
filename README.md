### Featured projects

#### ⚡ [Nexus — GitHub Ecosystem Lakehouse](https://github.com/Kaushik-Kishor/github-ecosystem-lakehouse)

> End-to-end lakehouse featuring historical GitHub event processing and repository Change Data Capture. Processed **5.5M+ GitHub events** from GH Archive through Bronze, Silver, and Gold Iceberg layers. Built a PostgreSQL → Debezium → Redpanda → Spark CDC pipeline with incremental Iceberg MERGE, persistent checkpoints, and source-to-target reconciliation across **852K+ repository records**. Orchestrated both pipelines using Apache Airflow and deployed and validated the workflows on AWS.

`Python` `PySpark` `Kafka` `Redpanda` `Debezium` `Apache Iceberg` `PostgreSQL` `Airflow` `Amazon S3` `AWS EC2` `Docker`

---

#### ⚡ [Real-Time E-Commerce Intelligence Platform](https://github.com/Kaushik-Kishor/ecom-intelligence-platform)

> Real-time streaming pipeline ingesting **15,000+ events** across 3 Kafka topics with approximately 3-second micro-batch latency. Implemented a Medallion Architecture on Azure Data Lake Gen2, dbt-modeled dimensional warehouse, and anomaly detection using Isolation Forest.

`Kafka` `Spark Structured Streaming` `dbt` `Azure Data Lake Gen2` `PostgreSQL` `scikit-learn` `Airflow`

#### 🚕 [Data Warehouse & ETL Pipeline — NYC Taxi](https://github.com/Kaushik-Kishor/nyc-taxi-datawarehouse-etl)

`Airflow` `PostgreSQL` `dbt` `Docker` `Python`

`Kafka` `Neo4j` `XGBoost` `Isolation Forest` `FastAPI` `React` `Python`
